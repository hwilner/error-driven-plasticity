# Deferred and Dropped Directions

This repository intentionally keeps several categories of work outside its public scope. The exclusions protect a simple, data-free foundation and prevent the repository from implying broader support than it provides.

## Deferred directions

Empirical data ingestion, source-specific adapters, data-dependent evaluation, and output-generation workflows are deferred. If considered in a separate context, they require their own governance, documentation, and boundary review; they are not represented here.

## Dropped from this public tree

The current tree does not include figure specifications or assets, generated summaries, archive indexes, downloaded material, source metadata, access records, notebooks, or raw and derived files. Tests that require any of those materials, or that write into repository data or output locations, are also excluded.

## Rationale

A synthetic model can communicate limited implementation ideas without importing external provenance, supporting outcome claims, or creating a false impression of broad reproducibility. The public boundary is therefore a design choice, not an omission to be inferred as a conclusion.

For the exact boundary, see [Release boundary](RELEASE_BOUNDARY.md). For the retained model’s limitations, see [Methods scope](METHODS_SCOPE.md).
